# skills

On-demand capabilities an agent loads by name (~70 tokens of metadata each, full instructions only when invoked).
A skill's description is its WHEN-to-use trigger; the body is a procedure with model-tier hints per step. Skills
span building (scaffolding, testing), meta/CEO operations (planning, orchestration, harness review), design/UX,
content, and self-improvement. They are the cheapest way to give an agent a reusable, progressively-disclosed
procedure without bloating the system prompt.
