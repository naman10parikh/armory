# identity

How an agent knows who it is and how it's addressed. Two layers: static identity files (a SOUL/persona, a brand, a
defined agent-file-format) that shape behavior and voice, and a runtime identity (a universal handle and channels)
that makes the agent reachable and auditable. Together they answer "who is this agent, what is it, and how do I
reach it" — the foundation of trust in any multi-agent system.
