## What it is
Enables MCP clients like Claude to connect to FitDays/iComon fitness tracking data via a self-hosted Cloudflare Worker, using OAuth login with FitDays credentials. It provides tools to list users and devices, retrieve weight history and latest weight, and trigger a sync.
