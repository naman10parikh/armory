## What it is
A read-only Model Context Protocol server that enables querying the official SEFAZ PI (Piauí State Revenue) system to request Certidão Negativa de Débitos (tax clearance certificates). It exposes one tool, works with any MCP client over HTTP, and operates on a prepaid, pay-per-use model.
