## What it is
CLI-first API testing tool with structured JSON failures (`failure_category`, `error_code`, `hints`) so AI agents can branch on the taxonomy without parsing stderr. MCP tools: `tarn_run`, `tarn_validate`, `tarn_fix_plan`, `tarn_inspect`, `tarn_rerun_failed`, and more. Tests are `.tarn.yaml`. Single static binary (musl), MIT.

## When to use it
When an agent needs the "Developer Tools" capability this MCP server exposes.
