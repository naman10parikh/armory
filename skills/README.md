# skills/ — Claude Code / agent skills (real vendored files)

The actual `SKILL.md` files (one folder per skill), vendored verbatim from upstream repos with a provenance header. ~1,130 skills.

- Browse/search them on the site, or pull one into your harness with `armory install <name>`.
- Full metadata (source, license, tags, related) for each skill → `brain/components/skills/<slug>.md`.
- Sourced from `anthropics/skills`, `obra/superpowers`, `davila7/claude-code-templates`, community skill packs, and more — see the homage in the root [README](../README.md).

This is the **catalog** of skills. Armory's own skill (the one that teaches an agent to use the registry) is `armory-skill/` at the repo root — not here.
